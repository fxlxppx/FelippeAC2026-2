## Comentários gerais
> Está separado em duas sessões, uma pastas contém o arquivo da unity para editar dentro da Engine e o outro é um executável do exercício para ver o comportamento das animações com shapekeys e controlar pelo teclado.
  
## Comentários Explicativos
> Fiz separado duas sessões: Exercicio3_Animacao é o projeto na Engine, o outro Exercicio3_exe é o executável do projeto, para rodar é só abrir o executável, no programa a animação irá acontecer automaticamente até ocorrer interações com o teclado:

> TECLA SPACE: Faz a animação automática parar e entra no modo manual de animação controlada pelo teclado, as keys podem ser mexidas individualmente.
> TECLAS Q/A: Controla a KEY 1, Q faz animação avançar e A reverte o movimento.
> TECLA W/S: Controla a KEY 2, W faz animação avançar e S reverte o movimento.
> TECLA E/D: Controla a KEY 3, E faz animação avançar e D reverte o movimento.
